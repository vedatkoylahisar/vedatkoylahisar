## 🚀 Featured Projects

### [MicroCommerce](https://github.com/vedatkoylahisar/MicroCommerce) — Microservices E-Commerce Platform
5 .NET 8 services (Catalog, Basket, Ordering, Identity, Messages) behind an Ocelot API Gateway, each with its own database. Checkout is asynchronous: Basket publishes events via MassTransit/RabbitMQ to Ordering. JWT auth with role- and ownership-based authorization, dependency-aware health checks, and xUnit integration tests that must pass in GitHub Actions before any Docker image is published.

`.NET 8` `MassTransit` `RabbitMQ` `MongoDB` `Redis` `PostgreSQL` `Ocelot` `Docker` `xUnit` `React`

### [Maxxing](https://github.com/vedatkoylahisar/maxxing_app) — Social Habit Tracking App
Track daily routines, keep streaks and stay motivated with friends in invite-code groups. All business rules live in the API: JWT auth, email verification with hashed, rate-limited codes, timezone-aware streaks and per-record privacy. Fully localized in Turkish and English.

`.NET 10` `EF Core` `PostgreSQL` `React Native` `Expo` `Docker`

Systematic review of 136 papers on deep learning for EEG emotion recognition, plus a hybrid 1D CNN-LSTM implemented on the DREAMER dataset (EEG + ECG) for valence/arousal classification.

`Python` `TensorFlow` `Signal Processing` `Deep Learning`
